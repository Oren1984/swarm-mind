# Music and narration: sources and licensing

## Background music

| | |
|---|---|
| Track name | "Swarm Mind — ambient bed" (untitled utility track) |
| Author | Generated by this repository's own code: `synthesize_music()` in [`scripts/build_video.py`](../../scripts/build_video.py) |
| Source URL | None. It is not downloaded from anywhere. |
| How it is made | Additive synthesis with NumPy: sine tones forming a slow four-chord pad (A minor, F, C, G; eight seconds each, cross-faded) plus sparse decaying sine "bell" notes on an A-minor pentatonic scale chosen by a fixed random seed. No samples, loops, presets, MIDI files or recordings of any kind are used. |
| License | Original work created for this project. It is covered by whatever license the repository owner applies to the repository. No third-party license applies. |
| Attribution required | None. |
| Third-party rights | None known. The chord progression is a common one and is not protectable; no existing melody was copied. |

Because the music is synthesized on the spot, there is no license to verify with an external party and no risk of having mistaken a freely downloadable track for a freely reusable one.

**Level.** The music is mixed 21 dB below the narration (RMS of music versus RMS of speech, measured during the build), then the whole mix is peak-normalized. See [validation.md](validation.md).

**Quality caveat.** It is a simple synthetic pad, chosen for licensing certainty over musical richness.

## Narration voice

| | |
|---|---|
| Voice | Microsoft Zira Desktop (English, United States) |
| Engine | Windows built-in speech synthesis (SAPI 5) through .NET `System.Speech`, driven by [`scripts/tts.ps1`](../../scripts/tts.ps1) |
| Where it runs | Entirely offline on the build machine. No cloud speech service, no account, no payment. |
| Cost | None. |

**Licensing status — please read.** The voice ships with Windows and was used on a licensed Windows 11 installation. I did not find, and therefore cannot cite, a Microsoft statement that explicitly grants or denies the right to redistribute audio produced by the built-in desktop voices in a public or commercial video. Use in a personal portfolio demonstration is common practice, but that is not the same as a verified license.

- This is disclosed as an **open point**, not claimed as cleared.
- If the video is to be used commercially or anywhere licensing certainty matters, the owner should either confirm the terms with Microsoft or re-render the narration with a voice whose license is explicit. `build_video.py` takes the narration from one function and a `--voice` option, so swapping the voice does not affect the rest of the pipeline; subtitles are re-timed automatically from the new audio.

No other third-party audio or visual material is used. Fonts in the cards and subtitles are Segoe UI as installed with Windows, rendered into pixels (the font files are not redistributed).
